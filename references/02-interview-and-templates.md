# 采集表 / 提问脚本 / 评分卡 / 交付模板（02-interview-and-templates）

> 本文件是 track-recommendation-skill 的 Step 1 与 Step 4 展开细则，模板可直接复制使用。

## 1. 必采信息清单

**自用 16 项**：
- 壁垒（6 项）：场地/货/技能/经历（含失败）/标签/别人反复找你帮的忙
- 产能约束（4 项）：每周可投入小时数/能扛多久没正反馈/单位产出耗时/预算
- 需求变现（4 项）：自己常消费且有标准/身边想消费而买不到/帮别人满足过且对方愿付钱/赚过轻松的钱
- 红线目标（2 项）：绝对不做的红线/唯一主目标

**给别人追加 8 项**（现状基线 4 + 人与动机 4，第 21–24 项最易被跳过却决定生死）：
- 现状基线：现有粉丝/数据基线/平台偏好/竞品偏好
- 人与动机：家庭支持/人设语气/表达风格/长期动机

**规则**：自用必采 16 项、给别人必采 24 项；缺任何一项在结论里显式声明「此项缺失，结论基于假设」。

## 2. 四区开放采集

| 区 | 内容 | 停止条件 |
|-|-|-|
| A 目的 | 唯一主目标（单选） | 能说出唯一目标 |
| B 资源九格 | 每格追到「具体发生过的一件事」，不接受形容词 | 每格能落到具体事件 |
| C 需求 | 需求三问 | 能判断有无外部付费证据 |
| D 约束动机 | 每周真实小时数/红线/能扛多久没正反馈 | 三者齐 |

**开门六要件**（齐 = L1 停采线，可给候选）：
1. 唯一主目标单选
2. ≥1 个结构性壁垒候选 T1–T4 附具体事件
3. ≥1 条已发生的付费/准付费需求证据
4. 每周真实可投入小时数
5. 红线
6. 能扛多久没正反馈

补齐预算/家庭支持/竞品偏好/人设语气/平台偏好 = L2 完整交付线。

## 3. 三类信息通道

| 标记 | 含义 | 例 |
|-|-|-|
| 【问】 | 问他本人，他手上有事实 | 你做过什么？每周能投几小时？ |
| 【看】 | 观察，不问（他会美化答案，或不自知其价值） | 别人反复找他帮同一个忙；吐槽能连讲 2 小时 |
| 【判】 | 顾问自己判断并给建议，不进问卷 | 交付形态/第一个付费产品/AI 能否覆盖 |

**跳过与补偿**：他有权不答，不得追问第二次，不得因 Skip 默认「他没有」；补偿三选一——【看】类补（翻公开账号/朋友圈/他人侧证）、【判】类推出（从已有信息保守推定）、标为假设写进交付「假设与待验证」区。

**停采前必做复述确认**：先复述①我听到的事实（逐条）②我据此推断的结论，让对方校正。

## 4. 提问脚本（推荐模式开场）

开场声明：「我会一直问到能给你推荐为止；任何一问你都可以不答，不追问，我会用别的方式判断。」

必问清单（一次问完 ≤5 问）：
1. 做这个账号最想达成什么（单选）
2. 手上有什么（时间/技能/资源/经历）
3. 帮别人解决过什么问题
4. 每周能投入几小时
5. 有没有绝对不做的红线

防失控约束：①每问必须能落到 D/I/S/C 或过滤器，说不出用途的不问；②分批只为依赖、不为控数量；③【判】类不进问卷。

## 5. 评分卡模板（候选赛道评分）

| 赛道候选 | D 需求 | I 不可替代 | S 供给力 | C 成本 | 适配度 D×I×S÷C | 档位 | 最低补足项 |
|-|-|-|-|-|-|-|-|
| 候选 A | | | | | | | |
| 候选 B | | | | | | | |
| 候选 C | | | | | | | |

档位：≥60 强推（值得长期押注）；40–59 可试（标注最低补足项，补齐后升级）；<40 慎选（换候选）。任一必要件为 0 → 全盘归零，直接排除。

**每项的 1/3/5 三档锚点**（避免自由心证）：

| 维度 | 1 分 | 3 分 | 5 分 |
|-|-|-|-|
| **D 需求强度** | 没人搜、没人付费 | 有人讨论、付费零星 | 有人在持续付费/反复追问 |
| **I 不可替代性** | 谁都能做 | 需要几个月学习 | 需要几年积累或特殊处境 |
| **S 可持续供给** | 选题 <10 个就枯竭 | 能做 30 期 | 能做 100 期以上 |
| **C 单位成本**（越高越糟） | 极高成本 1 | 中等 3 | 极低成本 5 |

适配度 = D × I × S ÷ C（满分 125）。

**S 行打分后必做子检验（2026-10-24 增补，不改变公式与权重）**：人格续航预检——用已采的每周工时、能否出镜/连续拍/是否需提词器 + 给别人选时的「能接受多久没正反馈」判读候选赛道形态与本人性格的消耗关系（引 CPF：日更出镜高能量赛道对低能量外放者是持续消耗；强观点赛道对低边界锋利者是慢性抗拒）。结论只写两种：①续航匹配（不影响排序）②续航存疑（同分候选排序降级 + 止损条款加预警）。**不得因续航调整 S 分数本身**——CPF 硬约束：人格仅解释社媒行为 5–15% 方差，不是命运判决。

**判读（经验阈值，待校准）**：≥60 赛道成立可投入；40–59 有硬伤，找出最低那项看能否抬起，抬不起则弃；<40 不成立换方向。

> **打分不能闭门填。** D 和 I 至少要有外部证据（一个真实询问 / 一条数据 / 一次付费），否则一律按 1–2 分计。

## 6. 赛道推荐卡模板（交付，一次 3–5 张）

| 推荐序 | 赛道名（含收窄路径示例） | 适配度 D×I×S÷C 档位 | 推荐理由（三问） | 证据依据 | 第一付费产品预设 |
|-|-|-|-|-|-|
| 1 | 应届生互联网求职 → 5 年 HR 讲面试避坑 | 80 强推 | 是你：5 年 HR＋面试官经历（T2）；市场：求职人群持续付费；能赢：亲历+时效差，AI 难替代 | 帮 30+ 人改简历被反复转介绍；评论区真实提问多 | 面试避坑咨询（市场价×0.6 起） |
| 2 | 职场沟通 → 给应届生讲向上汇报 | 55 可试 | 是你：同源 T2 能力迁移；市场：需求明确；能赢：可走 M4 更专业切分 | 需数据扫描补证（投流/付费社群/中腰部账号） | 1 对 1 沟通诊断咨询 |
| 3 | 泛职场口播（不做专业切分） | 30 慎选 | 是你：表达力尚可；市场：大；能赢：不可替代低，替代威胁高 | —— | —— |

## 7. 诊断模式七步输出清单

壁垒诊断 → T 型归类 → 3 个候选评分卡 → 推荐赛道与收窄路径 → 变量池证明 ≥30 → 交付形态建议 → 第一个付费产品预设 → 替代威胁判定 → 8 周试排期 → 止损条款 → 缺失项声明。

## 8. 数据扫描四路（诊断 Step 4）

| 路 | 证据 | 强度 |
|-|-|-|
| ① | 有人持续投流 | 最强信号（没人为不赚钱的事长期投） |
| ② | 有人在卖付费社群/课程/服务 | 强 |
| ③ | 评论区/问答区有真实提问 | 中 |
| ④ | 能找到已变现的中腰部账号 | 有=充分证据；无≠无路径（空白/变现看不见/检索不对），改走①②③ |

## 9. 止损条款（MVP 试跑与复盘）

- MVP：保留 2–3 个候选，每个各发 10–15 条，不做单点押注
- 达标信号优先级：**评论区开始自供选题 > 完播/主页访问/复访 > 涨粉**（涨粉是最容易自欺的一项）
- 预设 8 周试排期；未达标按止损条款停止，不盲目续投

## 10. 收敛追问与采集禁忌

> 收敛追问**不限项数**——只有在前一区答案不足以支撑判定时才追问，追加几个由信息缺口决定，不由配额决定。

| 他缺什么 | 这样追问 |
|-|-|
| 答得太宽 | 你最近三条内容具体在讲什么？ |
| 缺凭据 | 你在这领域做过最**具体**的一件事是什么？ |
| 商业目标不明 | 这号最终想接商单、卖产品、招人，还是纯记录？ |
| 风格不明 | 给选项让他挑：「你想显得像专业顾问，还是一起摸索的同行？」 |
| **天赋证据不足** | 做什么更容易开心、更容易被夸／被追问？不给钱也愿意熬夜研究的是什么？收藏夹里堆得最多的是什么？ |
| **需求证据不足** | 你自己花钱最多、买得最频繁的是什么？你或身边人最近想买但买不到／买到的不满意的是什么？ |
| **找不到对标中腰部** | **别急着扣分**——改问：「你在哪些**付费社群**里？里面最常被问的是什么？」 |
| **答到某个区就停了** | 对照开门六要件，缺哪一项就回到对应区继续问，**不要在这里替他补齐** |

**采集禁忌**：

- **不要问「你想让谁关注你」**——他答不出，这是你该推导出来的结果，不是提问起点
- 不要问「你的差异化优势是什么」——他答不上来，这本是你该分析出来的
- 不要问抽象的价值观问题（「你的初心是什么」）
- **不要问「说不出用途」的问题**——每个提问都要能落到 D／I／S／C／过滤器之一
- **不要把【判】类丢进问卷**——交付形态／第一个付费产品／AI 能否覆盖，都由你输出
- 答得含糊时**给选项让他挑**，别让他填空

## 11. 约束与动机区（决定能不能坚持）

> 这一区常被跳过，但**经验判断：大量「定位很好却做不下去」的根因在第 2 项，不在赛道上**。

```
1. 你为什么要做这件事？（面子/赚钱/转型/兴趣/家人要求）
2. 如果三个月没有正反馈，你还愿意继续吗？半年呢？一年呢？
3. 身边有没有人反对？他们反对的理由是什么？
4. 这件事假如做成了，你最想让谁知道？
```

## 12. 完整交付报告模板（诊断模式最终交付，十节）

```markdown
# 赛道诊断报告 ｜ [对象名] ｜ [日期]

## 一、壁垒诊断结论
- 判定的 T 型：T__（结构性/经营性）
- 证据：……
- 缺失项说明：本次未采集到 __ 项，以下结论基于假设……

## 二、一句话赛道陈述（待确认）
> 给【谁】，提供【什么】，因为我【凭据】。

## 三、候选赛道评分卡
| 候选 | D | I | S | C | 得分 | 结论 |
|-|-|-|-|-|-|-|

## 四、推荐赛道 + 收窄路径
原始词 → 第一刀 → 第二刀 → 第三刀 → 最终句
对标：@A（人群反向）/ @B（形式反向）/ @C（深度反向）

## 五、变量池证明（≥30 个取值）
1. 2. 3. …… 30.

## 六、第一个付费产品预设
产品 / 价格 / 谁买 / 为什么现在能卖

## 七、中腰部对标 + 反向操作点
| 对标 | 他做什么 | 我的反向点 |
|-|-|-|

## 八、8 周试跑排期
| 周 | 内容主题 | 拍摄准备 | 看什么数据 |
|-|-|-|-|

## 九、止损条款
- 试跑 10–15 条或 5–8 周，取先到者
- 达标信号优先级：评论区自供选题 > 完播/主页访问/复访 > 涨粉
- 不达标处理：调容器不硬做，优先调 I（加壁垒）和 S（收窄或放宽）
- 换赛道条件：连续两个容器失败，且三次 D 均为 0
- **断更归因顺序（2026-10-24 增补，引 CPF）**：角色距离→节律→危险组合→情绪→动机→形式，最后才查内容——断更期改内容是成本最高、命中率最低的动作

## 十、缺失项声明
本次未获得的信息 __，导致了 __ 的不确定性。
```

**报价原则：按周期报价，不按条。** 按条计价会诱导降低选题质量，是烂尾起点。

## 13. 客户版速查卡（可发给对方）

```
【本质】赛道 = 你能长期供货的、别人抄不走的交换结构
【公式】适配度 = D需求 × I不可替代 × S供给力 ÷ C成本
        乘法不是加法，任一项为 0 全盘归零

【三问定生死】
 1. 有人正在为这件事付钱吗？     → D
 2. 换个人来做得明显更差吗？     → I
 3. 能列出 ≥30 个不重样选题吗？  → S
 三个都答"是"才算候选

【天赋三角】占 2 条才算有天赋
 · 做得快 —— 学得比别人快
 · 有正反馈 —— 更容易开心、被夸/被追问/被转介绍
 · 肯投入时间 —— 不给钱也愿熬夜研究；收藏夹里堆得最多的是什么
 → 后两条最难伪装，只占"学得快"不算

【需求三问】他手上有证据，不靠想象市场
 · 自己花钱最多的是什么？有自己的评判标准吗？（你自己就是样本）
 · 身边有没有"想买但买不到 / 买到的都不满意"的？
 · 帮别人解决过什么？对方为这类事花过钱吗？（最关键）

【一票否决】
 × AI 或巨头一次升级就能覆盖，且你没有独属壁垒（★ 由顾问判）
 × 第一个付费产品给不出（★ 顾问先给预设，给不出才否决）
 × 同时想做 3 个以上赛道

【三类通道】问卷里只放【问】类
 【问】问他本人｜【看】观察现象｜【判】顾问输出（交付形态/第一个付费产品/AI 能否覆盖）

【中腰部论证】找到 = 有变现路径（照着学）
             找不到 ≠ 没有 —— 改查：有人持续投流 / 有人在卖付费产品 / 评论区有真实提问

【最高信号】不是播放量，是评论区开始替你出选题
```
