# track-recommendation-skill · 选赛道推荐与诊断技能

> 面向内容创作者 / 自媒体 / 个人 IP 的「赛道选择」技能：**采集用户信息 → 分析壁垒/天赋/需求 → 一次推荐 3–5 个候选赛道**（每个含推荐理由、适配度评分、证据依据、收窄路径示例、第一付费产品预设），并提供「这个赛道能不能做」的诊断模式。

这是一个面向 AI Agent 与人共同使用的**技能（Skill）**：`SKILL.md` 是执行入口，`references/` 是方法论与模板。基于马斯克第一性原理五步法自研（2026-10 原创，v2.1 修订 2026-10-25），已在飞书知识库「08-AI技能库」落地并编目。

> **v2.1 本次更新**：① 新增「入局前先过适配测试」前置路由（与 `selfmedia-fit-test-skill` 分工与共享采集项）② 新增 S 的**人格续航子检验**（引 CPF）与 **T4 身份承载力判定工具**（资产端五问 × 供给端供需比，引 IDF）③ `references/01` 并入方法库 14 法、案例矩阵 14 例、完整诊断信号谱 ④ `references/02` 并入评分卡 1/3/5 三档锚点、完整交付报告十节模板、客户版速查卡 ⑤ 修正案例统计（14 例中 10 例走 M4，唯一 M1 为反面教材）。

## 它解决什么问题

- 「不知道做什么方向」「不知道拍什么」「账号定位不清」——多数人给不出答案，不是没想法，是**没有判断结构**；
- 主流做法是「问你想做什么」，但多数人会回答「泛娱乐搞笑」「职场口播」这类**死局赛道**（加法直觉 9 分，乘法实况仅 15 分）；
- 选错赛道的根因：只看兴趣、不看「交换结构」（能否持续提供、谁愿意付钱、为什么是你）；
- 自欺性判断：把「有流量」当「有需求」，把「涨粉」当「达标」，把「蓝海」当「没人做」。

本技能用一套**行为化、证据驱动、带止损条款**的判断系统解决上述问题。

## 核心优势

1. **推荐模式（主）**：不是给一个答案，是一次给 3–5 张赛道卡供选择，每张含「推荐理由三问 + 适配度评分 + 证据依据 + 收窄路径 + 第一付费产品预设」。
2. **乘法模型 D×I×S÷C**：赛道是串联系统，任一必要件为 0 全盘归零——补齐最短板远优于拉高长板（反直觉，防「加法直觉」骗局）。
3. **结构性壁垒分类 T1–T8**：按「不可替代性来源」分型（资源场域/专业手艺/亲历经历/身份组合/信息差/人格表达/关系连接/耐受执行），强制至少一个 T1–T4 结构性壁垒入局，防「停手即衰减」的脆弱赛道。
4. **行为化证据纪律**：九格壁垒要求「具体到发生过的一件事，不接受形容词」；天赋三角（做得快/有正反馈/肯投入）占 ≥2 条；「自述不算数」。
5. **红线过滤 + 一票否决**：资质/合规/不愿露脸/家人反对/重资产，命中即删；替代威胁高且不可替代低、给不出第一付费产品、目标漂移（>3 赛道）、没有「只属于他」的壁垒——先执行，命中即出局。
6. **四象限定处置**：有天赋×有需求=当事业做；有天赋×无需求=当兴趣做（不报价）；无天赋×有需求=当生意做（给 SOP 不给人设）；无天赋×无需求=劝退+给「先去攒什么」。**多数「不知道做什么」的人落第四象限，此时给任何赛道方案都是害他**。
7. **诊断模式**：七步可行性判断——红线过滤→壁垒清点→收窄三刀（切完验 ≥30 个不重样选题）→数据扫描四路（投流/付费社群/评论区/中腰部账号，论证方向不搞反）→评分决策→MVP 试跑（2–3 候选各 10–15 条，不单点押注）→复盘止损（达标信号：评论区自供选题 > 完播/主页访问/复访 > 涨粉）。
8. **止损条款（GitHub 同类技能中独有）**：明确「涨粉是最容易自欺的一项」；预设 8 周试排期与停止标准，不盲目续投。
9. **诚实标注**：经验判断阈值（60/40 分档、变现优先级、信号权重）明确声明未做大样本校准，输出按「确定/经验判断/待验证」三层标注。
10. **人格续航预检（v2.1 新增，引 CPF）**：选题够 ≠ 做得动。日更出镜高能量赛道对低能量外放者是持续消耗；强观点赛道对低边界锋利者是慢性抗拒。**判读不新增采集项**，用途仅限候选排序降级与止损条款预警，**不得据此加分**（CPF 硬约束：人格仅解释社媒行为 5–15% 方差，不是命运判决）。
11. **T4 身份承载力判定工具（v2.1 新增，引 IDF）**：身份组合型不再靠顾问感觉——资产端五问（素材半径/圈层归属/转折存量/视角独占性/主张空间，各 1–5 分）× 供给端竞争度（供需比 = 月搜索量 ÷ 月新增有效笔记数；**>10:1 红利 / <3:1 内卷**）。实证锚点：同一位妈妈拍「儿童辅食」1.33:1（内卷）vs「婴儿面条」25:1（红利）——**身份不变，切口粗细差一个数量级**。
12. **入局前置路由（v2.1 新增）**：本技能只答「做什么方向」，不答「要不要做」。与 `selfmedia-fit-test-skill` 分工并共享 5 项采集项（已测过不重采）；两者同时被问时先跑适配测试，测出「暂不适合」则不进本技能——**方向选得再准，人留不住也是白搭**。

## 快速开始（AI 使用路径）

0. **先判前置路由**：用户问「适不适合做自媒体 / 要不要开始做 / 能不能做起来」→ 改道 **selfmedia-fit-test-skill**（本技能只答「做什么方向」）。两者同时被问时**先跑适配测试**，测出「暂不适合」则不进本技能。
1. **推荐模式**：用户说「帮我推荐几个赛道」「我适合做什么赛道」「账号定位」→ 进入采集 → 分析 → 一次输出 3–5 张赛道卡。
2. **诊断模式**：用户说「这个赛道能不能做」「帮我评估这个方向」→ 走红线→壁垒→收窄→数据扫描→评分→MVP→止损七步。
3. **必问清单（一次 ≤5 问）**：①最想达成什么（单选）②手上有什么（时间/技能/资源/经历）③帮别人解决过什么问题④每周能投入几小时⑤绝对不做的红线。
4. **完成证据**：≥3 张赛道卡，每张含推荐理由＋适配度＋证据依据＋收窄路径＋第一付费产品预设；信息不足时如实声明缺失项，禁止硬编赛道。

## 关键规则速览

- 赛道 = 交换结构，不是内容方向；不问「你想做什么」，问「你能持续提供什么、谁愿意付钱、为什么是你」。
- 一票否决最先执行；「蓝海」是三条 AND（市场足够大 且 确实有价值 且 同行还没研究透讲清楚），缺任一 =「没人做」→ 改走 M4 专业化切分（不换赛道，换切口）。
- 第一个付费产品默认答案 = **先卖咨询**（咨询是所有产品的「爹」，也是成本最低的需求验证）。
- 别人找你选赛道：采集以「能不能推荐」为停止条件，问到够为止；他有权不答，不得追问第二次，缺失项写进「假设与待验证」区。
- 报价按周期不按条；对方期待三个月爆火先对齐预期再报价，否则不接。
